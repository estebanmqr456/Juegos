Guia Rapida

  • Usa el buscador para filtrar por titulo, desarrollador o editor en tiempo real.
  • Filtra por hoster (ej. Gofile, Pixeldrain, 1fichier) o por tipo: game (instalador), goodie (extras) o patch (parches).
  • Haz clic en Ver archivos asociados en cualquier juego para ver los nombres exactos y tamanos de sus instaladores.
  • Usa Copiar enlaces para copiar todas las URLs de un titulo, o Descargar Todo (CSV) para abrir la lista completa en Excel.
